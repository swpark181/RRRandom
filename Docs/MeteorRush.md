# METEOR RUSH (운석 쟁탈전) — 규칙표 초안

하늘에서 떨어지는 **주사위 운석**이 부서지며 흩어진 **주사위 원석**을 모아, 팀 합계 77점을 먼저 지켜내는 3:3 모드.
킬은 점수가 아니라 원석을 빼앗는 수단. 굴려서 쓰는 **주사위**(E)는 지금 그대로이고, 원석과는 다른 물건이다.

## 기본

| 항목 | 값 |
| --- | --- |
| 인원 | 3 : 3 (혼자면 나 + 아군 봇 2 vs 적 봇 3) |
| 제한 시간 | 15분 |
| 승리 | 팀 합계 **77점 이상** + 상대보다 많음 → **12초 카운트다운** 버티기 |
| 카운트다운 취소 | 77점 아래로 떨어지거나 상대가 같거나 많아지면 취소, 다시 조건을 채우면 처음(12초)부터 |
| 체력·부활 | 지금과 같음 (체력 100, 4초 뒤 시작 위치에서 부활). 쓰러뜨려도 팀 점수는 오르지 않음 |

## 원석

| 이름 | 점수 | 모양 | 색 | 나오는 곳 |
| --- | --- | --- | --- | --- |
| 조각 (Shard) | 1 | 작은 큐브 결정 하나 | 민트 | 운석 파편, 쓰러진 사람이 흘린 것 |
| 원석 (Ore) | 3 | 바위 덩어리에 큐브 결정 3~4개가 솟음 | 분홍 | 운석 파편 |
| 큰 결정 (Big Crystal) | 6 | 큐브 결정 다발, 은은하게 빛남 | 버터·금 | 운석 한가운데 하나 |

- 걸어서 닿으면 자동으로 줍는다. 개수 제한 없음.
- 머리 위에 들고 있는 점수를 원석 아이콘 + 숫자로 표시 (`◆ 9`).
- **큰 결정을 든 캐릭터**는 몸이 금색으로 빛나고, 안개 속에서도 적 미니맵에 보인다.

## 운석

| 항목 | 값 |
| --- | --- |
| 첫 운석 | GO 후 10초에 떨어짐 (예고는 6초부터) |
| 간격 | 60초(1분)마다 1개 (연장전엔 황금 운석만) |
| 예고 | 떨어지기 **4초 전** 바닥에 그림자 원 + 줄어드는 링, 미니맵에도 표시 |
| 떨어지는 곳 | 양 팀 시작 위치에서 거리가 비슷한 가운데 줄 근처(팀 간격의 ±15%)의 평지에서 랜덤, 직전 지점과는 팀 간격의 28% 이상 떨어진 곳. 언덕·엄폐물·다리 위는 제외, 주사위 마을은 걸어서 갈 수 있는 곳 |
| 충돌 | 반경 안의 캐릭터를 밀어냄 (데미지 없음) |
| 한 운석에서 나오는 것 | 큰 결정 1 (6) + 원석 2 (3) + 조각 3 (1) = **15점** → 77점은 운석 6개 남짓 |

## 쓰러지면

- 들고 있던 **큰 결정은 그대로** 떨어진다 (계속 빛나는 목표물).
- 나머지 점수는 전부 **1점 조각으로 쪼개져** 사방으로 튄다 (9점이면 조각 9개).
- 섬 밖으로 떨어지면 들고 있던 원석은 사라진다. 바닥에 떨어진 원석은 사라지지 않는다.

## 시간이 끝나면

1. 팀 합계가 많은 팀이 승리.
2. 같으면 **황금 운석** 하나가 맵 가운데에 떨어지고, 그 안의 큰 결정을 **5초 동안 들고 있는** 팀이 승리. 황금 결정이 섬 밖으로 사라지면 황금 운석이 다시 떨어진다.

## 화면

- 위: `BLUE 12 · 8 RED`, 아래에 양쪽에서 30까지 차오르는 선 (`FIRST TO 30`) — 지금 점수 UI 재사용.
- 카운트다운: 화면 가운데에 팀 색으로 큰 숫자 `12…1`.
- 결과 화면 MVP: 경기 동안 원석을 가장 많이 주운 캐릭터 (같으면 쓰러뜨린 수).

## 봇

- 그림자 원이 뜨면 가까운 봇부터 그쪽으로 이동.
- 큰 결정을 든 적을 최우선으로 노림.
- 우리 팀 카운트다운 중에는 많이 든 봇이 뒤로 빠져 엄폐물 뒤에 숨음.

## 나중에 (1차 플레이 후 판단)

- 원석 3점 → 주사위 1개 교환 ("모아서 이길까, 깎아서 굴릴까").
- 운석 간격과 77점 목표는 실제 플레이 시간 보고 조정.
