Every object/prop made with Tripo for the RRRandom game must be in a cute cartoon style — soft, puffy, rounded (balloon-like) shapes and simple bold colors. Put "cute cartoon style" plus the shape feel in every Tripo prompt.

**Why:** The user rejected a plain foam-finger model as "너무 안 이쁘다" and asked for a balloon-like look, adding "항상 오브젝트 만들때는 카툰 스타일로" (2026-10-13).

**How to apply:** Write Tripo text/image prompts with "cute stylized cartoon, chunky rounded puffy shapes, glossy/clean colors"; show the result and ask before downloading. Studio text-to-3D (Model tab → pencil icon, H3.1, 30 credits each, several can be queued back to back) ignores shape words like "cube-shaped crystal" and falls back to generic hexagonal crystals/blobs (2026-10-19 Meteor Rush ore test), so for a specific silhouette make a concept image first and use image-to-3D.
