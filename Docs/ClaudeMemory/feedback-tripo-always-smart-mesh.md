From now on, whenever a 3D model is made in Tripo Studio, use **Smart Mesh** (P2.0) — for animal friends, cover props,
vehicles, map objects, everything. Don't use the HD / Ultra Mesh Quality / H3.1 generation. User: "앞으로 트라이포에서
모델링 할때 무조건 스마트매시 사용하도록 해줘" (2026-11-11).

**Why:** the user compared HD and Smart Mesh on the rabbit and the 16 cover props (round 94) and wants Smart Mesh for all models.

**How to apply:** Model tab → Smart Mesh: 100 credits for the mesh, then click "Texture 30" under the viewer (130 total).
Set Topology to Triangle and the polycount every time (it resets to Quad 5000): animal friends 20000, props ~6000.
Rename each export zip right away (Smart Mesh export ignores the file name). Details in [[tripo-smart-mesh]]; the
animal-friend skill step 5 says the same. Credit spending still only when the user asked for that step.
