The TPS-mode map for RRRandom is a separate map called "Dice Land": a floating sky island with rainbow dice, dice-canopy forest, clouds. First concept images (2026-10-14, Tripo web Image tool, Nano Banana Pro, 16:9) were judged "색감이 너무 물빠진것 같은데 조금 더 진하고 생동감" — colors must be vivid and saturated candy tones, not faded pastel.

**Why:** User wants lively color and a playable TPS layout; asked for "엄폐를 할 수 있는곳이 많았으면" without breaking the overall design.

**How to apply:** In Dice Land prompts/art, ask for vibrant saturated candy colors with strong contrast, and include lots of naturally placed cover (dice walls, stacked dice barricades, half-buried giant dice, hedges, pillars). No Tripo API key exists — generate images through the Tripo Studio website (studio.tripo3d.ai → Image) in Chrome. Related: [[tripo-cartoon-style]]

**v2 direction (2026-10-15):** user wants a ~10x larger map with many enterable/climbable buildings and a stronger MapleStory 2 stacked-block look; picked concept 1 (overview, char-pipeline/output/dice_land_v2_concept/01_overview.png) and it was built in code as "Dice Town" (see RRRandom HANDOFF 36차). Hard rules from the user: every 2-story building needs a way up, and every window must be big enough for any character (giants too) to jump out.
