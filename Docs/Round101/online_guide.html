친구와 온라인으로 RRRandom 하기

전용 서버 없이 한 사람이 방을 열고(호스트) 나머지가 들어갑니다. 최대 6명, 빈자리는 봇이 채웁니다. 상황에 맞는 방법 하나를 고르면 됩니다.

먼저 알아둘 것
  • 아직 배포용 실행 파일이 없습니다. 지금은 친구 PC에도 Unreal Engine 5.8과 이 프로젝트 폴더(빌드된 상태)가 있어야 합니다. 원하시면 설치 없이 실행되는 패키지 빌드를 만들어 드릴 수 있습니다(그러면 친구는 폴더만 받아 실행).
  • 호스트와 친구는 같은 버전이어야 합니다(같은 커밋).
  • 호스트가 나가면 게임이 끝나고 모두 타이틀로 돌아갑니다(호스트 넘기기 없음).

어떤 방법으로?

가장 쉬움 · 지금 바로 됨

① 같은 공유기 (집·사무실)

설정 없이 방을 찾아 들어갑니다.

서로 다른 집 · 지금 됨

② 주소(IP)로 직접 참가

호스트 쪽 공유기에서 포트 하나를 열거나, 가상 LAN 프로그램을 씁니다.

서로 다른 집 · 준비 필요

③ EOS (Epic 온라인 서비스)

포트를 열 필요가 없지만 Epic 개발자 포털 설정이 먼저 필요합니다.

① 같은 공유기에서

  1. 호스트: RRRandom 실행.bat → 타이틀에서 NETWORK → HOST GAME (또는 F1). 왼쪽 위에 HOSTING (LAN)이 보이면 열린 것.
  2. 친구: 같은 방법으로 실행 → NETWORK → JOIN GAME (또는 F2). 방 목록에서 고르면 들어갑니다.
  3. 처음 한 번 Windows 방화벽이 UnrealEditor 허용을 물으면 "개인 네트워크"에 허용합니다(호스트와 친구 모두).

나가기는 F3 또는 Esc → TITLE.

② 주소로 직접 참가 (서로 다른 집)

방 찾기는 같은 공유기 안에서만 됩니다. 밖에서는 호스트의 주소를 직접 넣어 들어갑니다(101차에 추가).

호스트가 할 일 — 둘 중 하나

  • 포트 열기: 공유기 설정의 "포트 포워딩"에서 UDP 7777을 호스트 PC로 보냅니다. 친구에게 알려 줄 주소는 공인 IP(검색창에 "내 IP")입니다.
  • 가상 LAN 프로그램(Tailscale, ZeroTier, Radmin VPN 같은 것)을 둘 다 설치해 같은 네트워크에 들어갑니다. 포트를 열 필요가 없고, 친구에게 알려 줄 주소는 그 프로그램이 보여 주는 호스트의 주소입니다.

그다음 ①과 똑같이 HOST GAME으로 방을 엽니다.

친구가 할 일

  1. 프로젝트 폴더의 RRRandom 친구 방 참가 (IP).bat을 실행합니다.
  2. Host address에 호스트가 알려 준 주소를 넣고 Enter (예: 203.0.113.7).
  3. Animal friend에 고를 동물친구 이름(Fox, Tiger, Rabbit, Squirrel, Dragon, RedFox)을 넣고 Enter. 비우면 Fox.

이미 게임을 켠 상태라면 `(물결 키)로 콘솔을 열고 RRJoinIP 203.0.113.7을 쳐도 됩니다.

③ EOS로 (포트 안 열고)

EOS가 연결을 중계해 줍니다. 무료지만 한 번 설정해야 합니다(지금은 키가 비어 있어 꺼져 있음).

  1. Epic Developer Portal에서 제품을 만들고 Product ID · Sandbox ID · Deployment ID를 확인.
  2. Product Settings → Clients에서 클라이언트 생성(정책 Peer2Peer) → Client ID / Secret.
  3. Epic Account Services에서 권한(Basic Profile, Online Presence, Friends)을 켜고 클라이언트 연결.
  4. Config/DefaultEngine.ini의 +Artifacts=(...) 줄에 위 값을 채움. (비밀 값이라 공개 저장소에는 올리지 않기)
  5. 호스트와 친구 모두 Epic 계정으로 로그인(개발 단계에서는 Dev Auth Tool, 또는 LoginType=accountportal).
  6. HOST GAME / JOIN GAME. 왼쪽 위가 HOSTING (EOS) / ONLINE (EOS)이면 성공.

자세한 단계는 프로젝트 README의 "EOS로 인터넷 플레이". 브랜드 심사 전에는 조직 멤버 계정만 로그인될 수 있습니다.

잘 안 될 때

증상볼 곳
방 목록이 비어 있음같은 공유기인지, 둘 다 방화벽 허용했는지. 다른 집이면 ②로.
주소로 들어가다 타이틀로 돌아옴호스트가 방을 열었는지, UDP 7777이 호스트 PC로 가는지, 주소가 맞는지. 버전이 다르면 거절됩니다.
상대가 순간이동하듯 끊김100차 이전 빌드에서 보이던 증상. 지금은 지연 200ms·손실 5%에서도 1초 중 가장 크게 튀는 거리가 39 → 6(참가자 화면, 측정)으로 줄었습니다.
왼쪽 위 노란 줄마지막 진행 상황/오류가 영어로 나옵니다. 자세한 건 Saved/Logs/RRRandom.log.

확인된 것과 아닌 것

  • 확인: 같은 PC에서 호스트 + 참가(방 찾기), 주소 직접 참가(127.0.0.1), 지연·손실을 건 상태의 움직임 보간.
  • 미확인: 실제로 다른 PC·다른 집에서 접속(포트 포워딩, 가상 LAN), EOS 경로.
  • 친구끼리 하는 것을 전제로 합니다(치트 방지는 약함).
