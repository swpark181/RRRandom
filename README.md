# RRRandom

무해한 랜덤 게임. 언리얼 엔진 5 C++ 프로젝트, 3D 탑뷰(쿼터뷰) 시점.

## 조작

| 입력 | 동작 |
| --- | --- |
| W A S D | 걸어다니기 |
| 마우스 왼쪽 클릭 | 커서 방향으로 원거리 공격 (누르고 있으면 자동 연사, 한 탄창 15발) |
| R | 재장전 (탄창이 비면 자동으로 재장전) |
| F | 가까운 탈것(킥보드/오토바이/자동차)에 타기 / 내리기 (아래 [탈것](#탈것)) |
| Space | 점프. 엄폐물 앞에서 누르면 위로 기어 올라감. 토끼는 공중에서 한 번 더(슈퍼 점프가 있으면 아주 높이), 용은 떨어지는 동안 누르고 있으면 활공. 비행 중엔 누르고 있는 만큼 떠오르고, 떼면 천천히 내려옴. 비행 중 두 번 빠르게 누르고 두 번째를 누르고 있으면 그동안 빠르게 대쉬 |
| E | 모아둔 주사위를 **하나** 굴리기. 머리 위에서 주사위가 0.6초 구르다 멈추면 효과가 적용됨 (구르는 동안엔 다음 주사위를 못 굴림). 공격력/공격속도/이동속도 중 하나 +5~30% (10~30초 중 랜덤), 또는 1/6 확률로 **무기 주사위**가 나와 새 무기를 받음, 1/5 확률로 캐릭터의 **전용 주사위**(호랑이 거인, 용 비행, 여우 투명화, 토끼 슈퍼 점프, 다람쥐 도토리 방패 — 아래 "캐릭터 키트") |
| F1 / F2 / F3 | 온라인 게임 열기(호스트) / 찾아서 참가 / 나가기 (아래 [온라인 플레이](#온라인-플레이)) |
| Esc | 일시정지 메뉴 (RESUME / TITLE). 혼자 할 때는 게임이 멈춤, 온라인에선 메뉴만 뜨고 게임은 계속. 메뉴에서 Esc 는 계속하기, Enter 는 타이틀로(온라인이면 나가면서). 결과 화면에서는 바로 타이틀로 |
| M (또는 왼쪽 위 미니맵 클릭) | 지도 전체 화면 / 닫기 (클릭이나 Esc 로도 닫힘). 미니맵 위 클릭은 사격하지 않음 |

### 치트 (테스트용, Shipping 빌드엔 없음)

| 입력 | 콘솔(`~`) | 효과 |
| --- | --- | --- |
| F6 | `RRWin` | 우리 팀이 바로 승리(점수 10), 결과 화면으로 |
| F7 | `RRGiant` | 거인 60초 |
| F8 | `RRFly` | 비행(날개) 60초 |
| F10 | `RRGod` | 무적 켜기/끄기: 어떤 공격에도 데미지 0(폼 핑거 등 찌르기 포함), 섬 밖으로 떨어지면 시작 위치로. 머리 위에 `GOD` 표시 |
| 1 ~ 7 | `RRGun <이름 또는 번호>` | 총 바로 받기: 1 PISTOL, 2 MINIGUN, 3 SMG, 4 RIFLE, 5 BLASTER, 6 CANNON, 7 FINGER(폼 핑거) (무기 주사위 6 품질, 랜덤 편차 없음, 탄창 가득) |
| (콘솔만) | `RROwnDie [눈] [1]` | 내 전용 주사위가 그 눈으로 바로 착지(기본 6). 뒤에 `1` 을 붙이면 봇까지 모든 캐릭터 |

- 서버에서 처리하므로 온라인 게임 중에도 내 캐릭터에만 적용됩니다. 시간은 플레이어 컨트롤러의 `CheatSeconds`, 총 품질은 `CheatGunQuality`.
- F5 는 엔진 디버그 키(셰이더 복잡도 화면)라 피했습니다. 화면 왼쪽 위에 치트 키 안내가 나옵니다.

## 타이틀 화면

게임(`-game` 실행)은 타이틀 화면에서 시작합니다. 배경은 Tripo 이미지 생성(Nano Banana Pro)으로 만든 그림 — 선착장의 여우가 라이플 총구의 연기를 불고, 머리 위에 무지개 주사위가 빛남 — 이고, 그 위에서 게임 속 주사위가 빙글빙글 돌며(Blender로 렌더한 24프레임) 번쩍이고 반짝임이 깜빡이며, 총구에서 연기가 피어오릅니다. 메뉴는 왼쪽(화면 폭 27% 지점)에 세로로, 왼쪽에 흰 빛이 번져 글자가 잘 보입니다. 캔버스에 직접 그림(`/Game/UI/T_Title*`). 모양은 아래 [UI 스타일](#ui-스타일).

- 로고 `RRRANDOM`(앞의 RRR 은 라벤더) 아래 파스텔 막대 5개, 버튼은 반투명 흰 알약(고른 것은 흰색 + 분홍 테두리).
- **캐릭터 고르기**는 초상화 카드 5장을 가로로: 고른 카드가 떠오르며 분홍 테두리와 이름 밑줄, 아래에 그 캐릭터 설명 한 줄, 그 밑에 BACK. A/D(←/→)로도 옮겨 다닙니다.

- **SINGLE PLAY** — 혼자 플레이 (나 + 아군 봇 2 vs 적 봇 3)
- **NETWORK** — **HOST GAME**(게임 열기) / **JOIN GAME**(찾아서 참가) / **BACK**. 위에 EOS로 할지 LAN으로 할지 표시됩니다.
- **QUIT** — 종료

W/S 또는 화살표로 고르고 Enter/Space로 누릅니다. 마우스를 올리면 선택되고 클릭하면 눌립니다.
Esc는 NETWORK 화면에서 뒤로 가기, 참가/열기 진행 중에는 취소입니다. 진행 상황과 실패 이유(`No game found...`, `Disconnected...`)는 버튼 아래 분홍 줄에 나옵니다.

- 타이틀 맵은 엔진의 빈 맵 `/Engine/Maps/Entry` 이고, `DefaultEngine.ini` 의 `GameModeMapPrefixes` 가 이름이 `Entry` 로 시작하는 맵에 `RRRandomTitleGameMode` 를 씁니다. 플레이 맵은 `DefaultGame.ini` 의 `ArenaMap`(지금은 `Template_Default`) 입니다. 우리 맵을 만들면 `ArenaMap` 을 바꿉니다.
- 에디터에서 Alt+P(PIE)는 지금 열린 레벨에서 바로 플레이하므로 타이틀을 거치지 않습니다. 또 PIE에서는 Esc가 플레이 종료라서 타이틀로 가려면 콘솔 명령 `RRTitle` 을 씁니다.
- 실행 옵션 `-RRSolo`, `-RRHost`, `-RRJoin` 을 붙이면 타이틀을 건너뜁니다.

## UI 스타일

깔끔한 파스텔톤, 단순하게 (49차, 시안 비교 후 "조합안"):

- **게임 중 HUD** — 상자 없이 글자와 가는 둥근 막대. 글자 뒤엔 가장자리가 흐린 반투명 흰 받침이 깔려 밝은 맵에서도 어두운 맵에서도 읽힙니다. 점수·주사위·탄약·팀원 카드는 묶음마다 받침 하나.
- **타이틀** — 왼쪽에 흰 빛을 번지게 하고 반투명 흰 알약 버튼, 캐릭터 고르기는 초상화 카드 5장 가로 배치.
- **결과·일시정지** — 반투명 흰 패널과 알약 버튼(주 버튼은 민트), 글자마다 색이 바뀌는 큰 제목. 결과 화면은 배경 음영 없이 게임 위에 바로, 일시정지는 옅은 라벤더 막.
- 색: 잉크 `#4A3F5C`, 분홍 `#F7A8C4`/`#F27FA6`, 민트 `#8FDDBE`, 라벤더 `#BDA6F0`/`#9A7BE0`, 버터 `#F7D88A`, 금 `#E9A93F`, 하늘 `#97C9F5`/`#66A5E6`. 파랑 팀은 하늘색, 빨강 팀은 분홍. 글꼴 Nunito(SemiBold/ExtraBold/Black, OFL).
- 시안 비교 페이지: https://claude.ai/artifact/48P8TVxc3WhCP533pVnEHJ

## 기본 플레이 (브롤스타즈식 팀전)

- 맵을 불러오면 화면 가운데 **5초 카운트다운**(GET READY 5…1, GO!)이 끝날 때까지 아무도(봇 포함) 움직이거나 쏘거나 주사위를 굴리지 못합니다. 새 게임도 마찬가지.
- 화면: 왼쪽 위 동그란 **미니맵**(흰 테두리; 지형을 파스텔로 밝게, 엄폐물·숲, 전장의 안개처럼 안 가 본 곳은 짙은 라벤더 안개, 지금 안 보이는 곳은 옅은 안개; 나 = 흰 화살표, 아군 = 하늘색 점, 쓰러진 아군 = X, 적은 우리 팀 시야에 있을 때만 분홍 점; 전체 화면은 둥근 모서리 네모), 오른쪽 아래 탄약 위에 **팀원 카드**(동그란 초상화, 이름, 체력, 주사위 수·거인·비행 남은 시간·총·재장전, 쓰러지면 흐려지고 KO).
- 3 대 3: 파랑 팀은 플레이어 스타트에서, 빨강 팀은 화면 위쪽 2000 거리에서 시작합니다. 혼자 하면 나 + 아군 봇 2 vs 적 봇 3 입니다. 온라인에서는 플레이어가 파랑, 빨강 순서로 번갈아 들어가 봇 자리를 대신합니다.
- 체력 100, 이동 속도 300. 공격은 FPS처럼 누르고 있으면 0.15초마다 한 발씩 나가고, 총알은 초속 5000으로 날아갑니다. 한 탄창 15발, 예비 탄약은 무한이고 재장전은 1.5초에 탄창 전체를 채웁니다. 사거리는 1300입니다.
- 맵 가운데에 엄폐물(회색 블록)이 있습니다. 총알과 캐릭터 모두 통과하지 못하므로 뒤에 숨으면 공격을 피할 수 있습니다. 레벨에 `RRRandomCover` 를 직접 배치하면 자동 배치는 하지 않습니다.
- 엄폐물 앞에서 Space를 누르면 위로 기어 올라갑니다 (발 위 200 높이까지, 0.45초). 점프 중에 엄폐물에 닿아도 0.5초 안이면 올라갑니다. 올라가는 동안은 쏠 수 없습니다.
- 엄폐물 위에서는 가장자리 밖으로 걸어 나가면 아래로 떨어집니다. 바닥에서는 지금처럼 맵 끝에서 멈춥니다. 점프로 맵 밖에 떨어지면 쓰러진 것으로 칩니다.
- 엄폐물 위에서 쏘면 커서가 가리키는 바닥 쪽으로 총알이 비스듬히 내려가서 아래층 캐릭터를 맞힐 수 있습니다. 커서를 캐릭터 위에 올리면 어느 층에 있든 그 캐릭터를 바로 겨눕니다. 반대로 아래에서 위에 선 캐릭터를 노리면 위로 쏩니다 (최대 50도). 같은 층끼리는 그대로 수평으로 쏩니다. 봇도 위아래에 있는 적을 향해 기울여 쏩니다.
- 3초 동안 쏘지도 맞지도 않으면 체력이 초당 15%씩 회복됩니다.
- 체력 0이 되면 쓰러졌다가 4초 뒤 시작 위치에서 다시 일어납니다. 쓰러뜨릴 때마다 상대 팀 점수 +1 (화면 위 `BLUE 0 · 0 RED`, 그 아래 양쪽에서 목표까지 차오르는 가는 선과 `FIRST TO 10`).
- **먼저 10킬(팀 점수 10)** 을 한 팀이 이기고 게임이 끝납니다. 아래 [결과 화면](#결과-화면).

### 결과 화면

- 게임이 끝나면 모두 멈추고(사격/이동/주사위/부활 없음, 날아가던 총알도 무효) 전장의 안개가 걷히며, 카메라가 **MVP**(가장 많이 쓰러뜨린 캐릭터; 같으면 이긴 팀, 그다음 서 있는 쪽)에게 1.6초에 걸쳐 MVP를 화면에 둔 채 돌아 내려가며 다가갑니다. 쓰러져 있던 MVP는 바로 일어납니다.
- 이긴 팀 여우들(과 MVP — 진 팀이어도)은 총을 집어넣고 **승리 춤**(Mixamo "House Dancing", 26초 반복)을 카메라 쪽(정면)을 보고 춥니다. 진 팀은 그대로 서 있습니다.
- 폭죽 불빛 속에서도 MVP가 잘 보이도록, 카메라 위에서 은은한 조명이 비추고 MVP 앞에서 폭죽이 터질 때마다 그 색 빛이 번쩍입니다(폭죽이 몸에 비치는 반사광처럼; 툰 재질이라 실제 반사는 안 보여서 빛으로 표현).
- MVP 눈높이 앞쪽(엄폐물·언덕이 화면 가운데와 양옆 어디에도 안 걸리는 각도를 골라)에서 천천히 좌우로 흔들리고, 해와 하늘빛이 어둑해진 뒤 뒤쪽 하늘로 **폭죽**이 계속 올라가 터집니다. 폭죽마다 색 있는 포인트 라이트가 번쩍여 주변을 비춥니다.
- 화면: 배경 음영이나 띠 없이 게임 화면 위에 바로 — 글자마다 색이 바뀌는 `VICTORY`(라벤더→분홍→금색)/`DEFEAT`(하늘→라벤더), 반투명 흰 알약에 최종 점수, 양쪽에 반투명 흰 패널의 팀별 킬 수(MVP 금색 표시), 아래 동그란 초상화가 든 `MVP 이름 N KO` 알약, 버튼 **NEW GAME**(Enter, 민트) / **TITLE**(Esc, 흰색).
- NEW GAME 은 같은 맵을 처음부터 다시 엽니다. 온라인 게임에서는 호스트만 누를 수 있고 참가자 화면엔 `WAITING FOR HOST` (호스트가 누르면 참가자도 같이 넘어감).
- 목표 점수는 게임 모드의 `ScoreToWin`(기본 10). 테스트할 때는 명령줄에 `-RRScoreToWin=2` 처럼 바꿀 수 있습니다.
- 주사위는 3개를 가지고 시작하고, 15초마다 1개씩 쌓입니다 (게이지).
- 쓰러지면 받고 있던 주사위 버프와 아직 구르던 주사위는 사라지고, 모아둔 주사위는 남습니다.
- 공격속도 버프는 연사 간격과 재장전 속도 둘 다 빠르게 합니다.
- 봇도 주사위를 모으고 굴립니다. 적이 사거리 근처에 오면, 또는 싸움이 없어도 2~4개 쌓이면 굴리기 시작해서 다 쓸 때까지 하나씩 이어서 굴립니다.
- 봇은 조심스럽게 싸웁니다. 적을 처음 보면 잠깐 반응 시간을 두고, 3~5발씩 끊어 쏘고, 엄폐물에 가려지면 쏘지 않습니다. 재장전하거나 다쳤을 때는 엄폐물 뒤로 숨고, 주변에 적이 없으면 미리 재장전합니다.

### 규칙: METEOR RUSH (운석 쟁탈전)

타이틀에서 시점(과 맵)을 고른 뒤 **PICK A RULE** 에서 **KNOCKOUT**(위의 10킬 선승) 또는 **METEOR RUSH** 를 고릅니다. 명령줄 `-RRRule=MeteorRush` 도 같습니다. 참가자는 호스트의 규칙을 따릅니다. 기획: `Docs/MeteorRush.md`.

- 하늘에서 **주사위 운석**이 떨어지고, 그 안에서 나온 **주사위 원석**을 모아 **팀 합계 77점**을 들고 버티면 이깁니다. 킬은 점수가 아니라 원석을 빼앗는 수단입니다. E 로 굴리는 주사위는 그대로입니다.
- 원석(투명한 사탕 유리 안에 진짜 주사위가 비침, 둥실 떠서 천천히 돔): **조각** 1점(민트, 흰 주사위 1개), **원석** 3점(분홍, 분홍 주사위 3개), **큰 결정** 6점(호박색 결정 속 빛나는 6눈 주사위). 닿으면 줍습니다. 머리 위에 `ORE 9` 태그(큰 결정을 들면 금색).

- 굴린 주사위가 1/5 확률로 비행 주사위(`5 FLY`, 분홍색)가 됩니다 — **용만**("캐릭터 키트"). 치트 F8은 누구나.
- 비행 중에는 **Space를 누르고 있는 만큼 떠오릅니다** (초속 약 885, 최대 0.75초 → 약 680, 뗀 뒤 0.2초 더 올라 최고 약 770). 떼면 위로 가던 힘이 곧 멈추고 **천천히 내려옵니다** (중력 0.25배, 최대 낙하 속도 250 → 770에서 약 3초). 공중에서 방향 조종이 잘 됩니다 (AirControl 0.8).
- 높이 상한: 발이 경기장 바닥에서 **캐릭터 키(192)의 5배 = 960** 위로는 못 올라갑니다 (`FlightMaxHeightInBodies`, 거인이어도 보통 키 기준). 상한에서 Space를 계속 누르면 그 높이에 떠 있습니다. 지금 설정(한 번에 0.75초)으로는 바닥에서 약 770, 엄폐물 위에서 이륙하면 상한(960) 근처까지 가고, `FlightRiseSpeed`/`FlightMaxHoldTime` 을 올렸을 때의 안전장치입니다.
- **대쉬**: 비행 중 Space를 0.3초 안에 두 번 누르고 **두 번째를 누르고 있는 동안** 빠르게(속도 1200, 걷기의 4배) 높이를 유지한 채 날아갑니다. WASD로 방향을 틀 수 있고, 입력이 없으면 보는 방향으로 갑니다. 떼면(또는 비행 시간이 끝나면) 공중 속도로 줄고 다시 활공합니다. **한 번 비행에 한 번**: 떼고 나면 착지했다가 다시 떠야 또 쓸 수 있습니다. 엄폐물에 부딪히면 막힙니다. 왼쪽 아래 줄에 `[SPACE x2 HOLD] DASH` / `DASHING` / `DASH AFTER LANDING`. 조절: `DashDoubleTapTime`, `DashSpeed`. 봇은 대쉬하지 않습니다. 길게 누르면 맵 끝 너머까지 갈 수 있으니 주의 (맵 밖 낙하 = 쓰러짐).
- 땅에 닿아야 다시 떠오를 수 있습니다 (공중 재점프 없음). 날면서 쏠 수 있고, 아래에 있는 적에게는 기울여 쏩니다. 엄폐물 위로 날아가 바로 내려앉을 수 있습니다 (비행 중엔 기어오르기 대신 비행).
- 지속 시간은 6초 + 눈 1개당 1초 (7~12초). 공중에서 시간이 끝나도 땅에 닿을 때까지는 천천히 내려옵니다. 맵 밖으로 날아가 바닥 아래로 떨어지면 그때부터는 보통 속도로 떨어집니다 (맵 밖 낙하 = 쓰러짐).
- 봇도 비행 주사위가 나오면 적이 가까울 때 0.3~1.5초마다 0.25~0.75초씩 떠올랐다가 내려옵니다.
- 머리 위에 `FLY` 칩 (거인과 같이 있으면 `[GIANT] [FLY]`), 내 캐릭터면 왼쪽 아래에 `FLY  HOLD [SPACE] TO RISE  8s`.
- 비행 중에는 등에 **분홍 깃털 날개**가 붙습니다 (빛을 받지 않는 발광 머티리얼, 빛 번지는 흰 테두리, 깃털 위에서 별빛처럼 번쩍이는 반짝임, 날개에서 떨어져 흩날리는 분홍 별 가루 — 오를 때 많이, 땅에선 조금). 땅에서는 등 뒤에 작게 접혀 있고, Space로 오를 땐 크게 날갯짓, 활공할 땐 펼친 채 천천히 물결, 대쉬할 땐 뒤로 젖힙니다. 비행이 시작되면 0.25초에 걸쳐 펼쳐지고 끝나면 접히며 사라집니다 (공중에서 시간이 끝나도 착지할 때까지는 유지).
- 조절: 캐릭터의 `FlightRiseSpeed`, `FlightMaxHoldTime`, `FlightMaxHeightInBodies`, `FlightAirControl`, `FlightBaseDuration`, `FlightSecondsPerPip`, 이동 컴포넌트(`URRRandomMovementComponent`)의 `GlideGravityScale`, `GlideBrakeGravityScale`, `GlideMaxFallSpeed`, 주사위 컴포넌트의 `FlightDieChance`, 봇의 `FlightHopDelay`, `FlightHoldTime`.

### 탈것

- 맵에 탈것 6대가 세워져 있습니다: 각 팀 앞쪽에 **킥보드**와 **오토바이** 하나씩, 가운데 양옆에 **자동차**(오픈카) 두 대. 가까이 가면 발밑에 `[F] RIDE ...` 가 뜨고, F 로 타고 다시 F 로 내립니다(탈것 옆으로 비켜 섬).
- 속도: 킥보드 걷기의 1.3배 → 오토바이 1.6배 → 자동차 1.9배 (주사위 이동속도 버프는 그 위에 곱해짐).
- **드리프트**: 오토바이와 자동차는 접지력이 낮아서, 빠르게 달리다 급하게 꺾으면 차체는 새 방향을 보는데 몸은 원래 방향으로 미끄러집니다. 오토바이는 그때 회전 안쪽으로 크게 기울고, 자동차는 살짝 롤.
- **자동차는 앞뒤 2인승**(색동 블록 무지개 차): 누가 운전 중일 때 다른 캐릭터가 옆에서 F 를 누르면 `[F] RIDE CAR (BACK SEAT)` — 운전석 바로 뒷자리에 타서 함께 이동합니다(뒷사람은 직접 움직일 수 없고 사격은 가능). 뒷사람은 F 로 언제든 내리고, 운전자가 내리거나 쓰러지면 뒷사람도 같이 내립니다.
- 타는 동안: 사격·재장전·주사위는 그대로, 점프/기어오르기는 안 됨. 쓰러지면 그 자리에 탈것이 남고, 비행 주사위로 날아오르거나 거인이 되면 자동으로 내림(거인·비행 중엔 탈 수 없고 `[F] RIDE` 안내도 안 뜸). 탈것은 충돌이 없어서 총알·캐릭터·시야를 막지 않음. 안개 속 적이 탄 탈것은 적과 함께 숨겨짐.
- **봇도 탑니다**: 교전 중(적이 사거리 근처에 보이거나 맞는 중)이 아니고 가려는 곳(멀리 보이는 적, 마지막으로 본 곳, 순찰 지점)까지 1400 이상일 때, 1000 안에 빈 탈것이 있으면 걸어가서 타고 이동합니다. 목적지 500 안에 오거나, 막혀서 못 가거나, 교전이 시작되면 내립니다. **아군(플레이어 포함)이 탄 자동차가 600 안에 서 있고 뒷좌석이 비어 있으면** 거리와 상관없이 뒷좌석에 타고, 운전자가 내리거나 교전이 시작되면 내립니다.
- **스키드 마크**: 오토바이와 자동차가 드리프트하면 뒷바퀴 자리에 타이어 자국이 남습니다. 빠를수록 진하고 넓으며, 2초 뒤부터 3초에 걸쳐 옅어져 사라집니다.

## 처음 열기

1. Unreal Engine 5.8과 Visual Studio 2022(“C++를 사용한 게임 개발” 워크로드)를 설치합니다.
   다른 5.x 버전을 쓰면 `RRRandom.uproject`의 `EngineAssociation` 값을 그 버전으로 바꾸거나,
   `.uproject` 파일 우클릭 → *Switch Unreal Engine version* 을 씁니다.
2. `git lfs install` 을 한 번 실행합니다. 맵과 에셋(`.uasset`, `.umap`)은 Git LFS로 관리합니다.
3. `RRRandom.uproject` 를 더블클릭합니다. 모듈을 빌드할지 물으면 *예* 를 누릅니다.
   (또는 우클릭 → *Generate Visual Studio project files* 후 `RRRandom.sln` 에서 `Development Editor` 로 빌드)
4. 처음에는 엔진 기본 레벨(`Template_Default`)이 열립니다. 바로 플레이(Alt+P) 해볼 수 있습니다 (타이틀 화면은 `-game` 실행 때만 나옴).
   레벨에 과녁(`RRRandomDummy`)이 하나도 없으면 시작 위치 앞에 3개가 자동으로 세워집니다.
5. Rider로 열 때 "로드 실패"가 나면 .NET 10 SDK가 설치되어 있는지 확인합니다. UE 5.8의 UnrealBuildTool은 .NET 10이 필요합니다.

   (바뀐 ini 파일을 같이 커밋해 주세요.)
3. 과녁은 *Place Actors* 에서 `RRRandomDummy` 를 찾아 원하는 곳에 끌어다 놓습니다.
   자동 배치는 게임 모드의 `bSpawnDummies` 를 켰을 때만 합니다(기본 꺼짐, 팀전 한가운데에 서 있게 되므로).
4. 팀 인원과 팀 시작 거리는 게임 모드의 `TeamSize`(기본 3), `TeamSpawnDistance` 로 바꿉니다.
   `bSplitPlayersAcrossTeams` 를 끄면 온라인 플레이어가 모두 파랑 팀에 들어가 봇과 싸웁니다.
   바닥이 없는 자리에는 아무도 세우지 않고 로그에 경고를 남깁니다.

## 온라인 플레이

전용 서버 없이, 플레이어 한 명이 호스트(리슨 서버)가 되고 나머지가 접속합니다.
체력, 탄약, 무기, 주사위, 쓰러짐, 점수, 봇은 모두 호스트가 계산하고 다른 플레이어에게 복제합니다.

| 키 | 동작 |
| --- | --- |
| 타이틀 NETWORK → HOST GAME, 또는 F1 | 게임 열기. 플레이 맵을 리슨 서버로 (다시) 불러옴 |
| 타이틀 NETWORK → JOIN GAME, 또는 F2 | 게임을 찾아 첫 번째에 참가 |
| F3 | 나가서 다시 혼자 플레이 |
| Esc → TITLE (일시정지 메뉴) | 나가서 타이틀로 |

화면 왼쪽 위에 연결 상태(`SOLO` / `HOSTING (LAN) 2 PLAYERS` / `ONLINE (EOS) ...`)와 마지막 진행 상황(노란 줄)이 나옵니다.
콘솔 명령 `RRHost`, `RRJoin`, `RRLeave`, `RRTitle` 도 같고, 실행 옵션 `-RRHost`, `-RRJoin` 을 붙이면 타이틀을 건너뛰고 시작하자마자 열기/참가합니다.

### 바로 테스트하기 (LAN, 설정 필요 없음)

EOS 키가 비어 있으면 엔진이 EOS 대신 Null 서브시스템을 쓰고, 게임은 LAN 브로드캐스트로 찾아 IP(포트 7777)로 접속합니다.
같은 PC 두 창이나 같은 공유기의 PC끼리 바로 됩니다. 실행 옵션 `-RRLan` 을 붙이면 EOS가 설정돼 있어도 LAN을 씁니다.

```powershell
$ue = "C:\Program Files\Epic Games\UE_5.8\Engine\Binaries\Win64\UnrealEditor.exe"
$proj = "C:\work\RRRandom\RRRandom.uproject"
& $ue $proj -game -windowed -ResX=960 -ResY=540 -WinX=0 -WinY=0 -RRHost     # 호스트
& $ue $proj -game -windowed -ResX=960 -ResY=540 -WinX=960 -WinY=0 -RRJoin   # 참가
```

다른 PC에서 접속할 때 Windows 방화벽이 UnrealEditor 허용을 물으면 허용합니다.
게임 로직만 볼 때는 에디터에서 *Play → Net Mode: Play As Listen Server*, *Number of Players: 2* 로도 됩니다 (세션 없이 바로 연결).

### EOS로 인터넷 플레이

EOS는 P2P 연결을 중계해 주므로 포트 포워딩이 필요 없습니다. 무료입니다.

1. [Epic Developer Portal](https://dev.epicgames.com/portal)에서 제품을 만들고 *Product Settings* 에서 Product ID, Sandbox ID, Deployment ID를 확인합니다.
2. *Product Settings → Clients* 에서 클라이언트를 만듭니다. Client Policy는 **Peer2Peer**. Client ID와 Client Secret을 받습니다.
3. *Epic Account Services* 에서 애플리케이션의 Permissions(Basic Profile, Online Presence, Friends)를 켜고, Linked Clients에 2번 클라이언트를 연결합니다.
4. `Config/DefaultEngine.ini` 의 `+Artifacts=(...)` 줄을 채웁니다. `ClientEncryptionKey` 는 64자리 16진수 아무 값이면 됩니다.
   ```powershell
   -join ((1..64) | ForEach-Object { '{0:X}' -f (Get-Random -Maximum 16) })
   ```
   Client Secret이 이 파일에 들어가므로 공개 저장소라면 이 줄은 커밋하지 마세요.
5. 포털에서 EOS SDK를 받아 `SDK/Tools` 의 Dev Auth Tool을 실행합니다. 포트 `6547` 로 열고 Epic 계정으로 로그인해 이름 `Player1` 로 credential을 추가합니다.
   같은 PC에서 두 번째 게임을 띄우려면 다른 Epic 계정을 `Player2` 로 추가하고, 그 게임에는 `-RRDevAuth=Player2` 를 붙입니다.
6. 한쪽에서 HOST GAME(F1), 다른 쪽에서 JOIN GAME(F2). 왼쪽 위에 `HOSTING (EOS)` / `ONLINE (EOS)` 가 보이면 성공입니다.
   실패하면 노란 상태 줄과 `Saved/Logs/RRRandom.log` 의 `LogEOS`, `LogOnline` 줄을 봅니다.

- 친구 PC도 각자 Dev Auth Tool로 로그인합니다. 브랜드 심사를 받기 전에는 조직(Organization) 멤버 계정만 로그인될 수 있으니, 안 되면 친구 계정을 조직에 추가합니다.
- 로그인 방식은 `Config/DefaultGame.ini` 의 `LoginType` 으로 바꿉니다 (`accountportal` 은 Epic 로그인 창). `-AUTH_TYPE=... -AUTH_LOGIN=... -AUTH_PASSWORD=...` 실행 옵션이 있으면 그것을 씁니다.

### 동작 방식과 제약

- 호스트는 혼자 할 때와 같은 게임을 돌리고, 플레이어가 들어오면 파랑, 빨강 순서로 봇 자리를 하나씩 대신합니다. 플레이어가 나가면 봇이 다시 그 자리를 채웁니다.
- 참가자는 이동을 언리얼 기본 캐릭터 이동 예측으로 하고, 연사 쿨다운만 자기 쪽에서 계산해 발사·재장전·주사위·오르기를 호스트에 요청(RPC)합니다. 탄약과 무기는 호스트 값이 돌아와 표시됩니다.
- 엄폐물 오르기는 캐릭터 이동 예측에 포함되지 않아서, 참가자가 오르는 동안과 끝난 뒤 0.5초는 호스트가 그 참가자의 위치를 그대로 믿습니다. 치트 방지가 약하므로 친구끼리 하는 것을 전제로 합니다.
- 호스트가 나가면 게임이 끝나고 참가자는 타이틀 화면으로 돌아갑니다 (`Disconnected: ...` 표시, 호스트 이전 없음).

- `URRRandomKitComponent` / `FRRKit` (`RRRandomKit.h/.cpp`) — 캐릭터 키트: 종별 패시브 수치와 전용 주사위 확률 표(`RRKit::Get`), 전용 주사위 상태(투명화·슈퍼 점프·보호막·원석 자석 — 서버가 정하고 복제), 기계마다 그리는 것(투명화 머티리얼을 보는 쪽이 나/아군/상대인지에 따라, 보호막 유리 방울). 캐릭터는 체력·점프 횟수·주사위 확률(`ApplyKit`), 이동 속도, 밀려남(`LaunchCharacter`), 활공, 슈퍼 점프, 피해(보호막·등 뒤 공격), 쓰러질 때(총 지키기)에서 이걸 읽음. 봇·미니맵은 `IsNoticedByTeam`(시야 + 투명화)으로 상대를 봄
- `URRRandomDiceBuffComponent` — 시간에 따라 게이지를 채워 주사위를 쌓고, E로 하나씩 굴림. 굴리는 순간 결과(눈, 종류)를 정하고 `RollSpinTime`(0.6초) 뒤 착지할 때 눈금만큼 시간제 버프를 줌. 같은 능력치 버프는 더해짐. 무기 주사위가 나오면 `OnWeaponDie` 로 알려서 캐릭터가 무기를 바꾸고, 거인 주사위가 나오면 `OnGiantDie` 로 알려서 캐릭터가 거인이 되고, 비행 주사위가 나오면 `OnFlightDie` 로 알려서 캐릭터가 날 수 있게 됨, 전용 주사위는 `OnOwnDie`. 거인·비행·전용 주사위 확률은 캐릭터가 종에 따라 정함(`FRRKit`). 게이지, 주사위, 버프, 굴림 결과는 호스트가 계산해 복제함
- `URRRandomGunComponent` — 손에 든 총. 무기마다 자기 모델(`/Game/Props/Guns/SM_Pistol`, `SM_Smg`, `SM_Minigun`, `SM_Blaster`, `SM_Cannon` — Tripo 카툰 장난감 총, `C:\work\char-pipeline\scripts\blender_guns.py` → `ue_import_props.py`; 길이와 총구 끝은 `GunLooks` 표), 라이플과 모델이 없는 무기는 라이플(`/Game/Props/Rifle/SM_Rifle`). 매 프레임 애니메이션 뒤에 손잡이(장난감 총은 `GunLooks` 의 쥐는 자리)를 오른손바닥, 총구를 왼손 쪽으로 놓아 어떤 자세든 두 손 사이를 따라감. 쏠 땐 몸 애니메이션이 두 손을 사격 방향으로 맞추므로 총도 그대로 사격 방향. 그 자세의 총구 끝 위치를 기억해(`GetAimMuzzleOffset`) 총알이 거기서 나감(처음 보기 전엔 `MuzzleOffset` (70, 12, 2)). 쏘지 않을 땐 통통한 몸에 묻히지 않게 `HoldOffset` 만큼 앞으로 내밈. 마네킹(손 뼈 없음)과 KO 중엔 숨김. 모델은 `C:\work\char-pipeline\scripts\blender_rifle.py` → `ue_import_rifle.py`
- `URRRandomWingsComponent` — 비행 날개. `/Game/Effects/Wings/SM_Wing` 두 개(왼쪽은 Y 반전)를 게임 중에 만들어 여우의 `spine2` 뼈 뒤에 붙이고, 상태(땅/상승/활공/대쉬)별 자세(들어 올림, 뒤로 젖힘, 날갯짓 각도/속도, 크기) 사이를 부드럽게 오가며 날갯짓함. 모든 기기에서 각자 (복제된 비행 여부와 이동 상태로 판단), 충돌/그림자 없음. 메시/머티리얼은 `C:\work\char-pipeline\scripts\blender_wing.py` → `ue_import_wing.py`
- `URRRandomFlightEffectsComponent` — 높이를 위에서 읽히게 하는 연출(모든 캐릭터): 발밑 둥근 그림자 데칼(높이 오를수록 작아짐, `/Game/Effects/Flight/M_BlobShadow`), 점프/비행 이륙과 높은 곳 착지 때 흙먼지 고리(`M_DustRing`), 빠르게 날 때 뒤로 남는 바람 줄(`M_WindStreak`). 머티리얼은 `C:workar-pipelinescriptsE_make_flight_fx.py`. 비행 중엔 몸이 속도에 따라 앞으로 최대 18° 기울고, 내 카메라가 조금(최대 12%) 물러남. 카메라는 피치 -70°, FOV 30(조금의 원근으로 날아오르면 커 보임).
- `URRRandomOverheadDieComponent` — 머리 위 3D 주사위(`/Game/Props/Dice/SM_Dice`). 굴림이 복제되면 각 기기에서 튀어 오르고, 호를 그리며 구르다 감속해 나온 면이 그 기기의 카메라를 보게 멈추고(살짝 튐), 머물렀다 작아지며 사라짐. HUD가 머리 위 표시의 맨 위 위치를 알려 주면(`SetStackTop`) 그 위에 뜸. 보이기만 하는 컴포넌트라 복제/충돌/그림자 없음. 면 방향 표는 메시의 면별 눈 개수를 세어 확인한 것 (`SM_Dice` 를 다시 만들면 확인 필요)
- `ARRRandomHUD` — 캔버스에 파스텔 스타일로 그림(`RRRandomUIStyle`). 모든 캐릭터 머리 위에 무기, 체력, 주사위 개수/게이지, 버프, 굴림 결과, 데미지 숫자를 표시하고, 화면에는 팀 점수, 내 주사위 패널, 남은 탄약, 부활 카운트다운, 왼쪽 위 온라인 상태를 표시. 시작 카운트다운, 팀원 카드(초상화 `/Game/UI/T_FoxPortrait` — `C:\work\char-pipeline\scripts\blender_portrait.py`), 미니맵(섬 지도에서 지형 색을 한 번 만들고 0.12초마다 파스텔로 밝히고 라벤더 안개를 칠한 288×288 텍스처를 원 안에 + 실시간 표시, 전체 화면 전환)은 `RRRandomHUDPanels.cpp`
